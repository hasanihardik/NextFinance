# Finance SaaS Platform

A full-featured Finance SaaS platform built with Next.js 14, Hono.js, and Drizzle ORM.  
Track income and expenses, categorize transactions, import CSVs, connect bank accounts using Plaid, and monetize with Lemon Squeezy.  

## 🚀 Features
- 📊 Interactive financial dashboard with changeable charts  
- 🗓 Account and date filters  
- 💹 Transactions table with bulk delete & search  
- 🔄 CSV transaction imports  
- 🔗 Bank connections via Plaid & subscription management  
- 🔐 Authentication via Clerk  
- 💾 PostgreSQL & Drizzle ORM  
- 🎨 Styled with TailwindCSS & Shadcn UI  
- 🚀 Deployed on Vercel  

## 🛠 Tech Stack
- **Frontend:** Next.js 14, TailwindCSS, Shadcn UI  
- **Backend:** Hono.js API, Tanstack React Query for state management  
- **Database:** PostgreSQL with Drizzle ORM & Neon DB  
- **Authentication:** Clerk  
- **Payments:** Lemon Squeezy  
- **Deployment:** Vercel  

## 📂 Project Setup  
```bash
git clone <repo-url>
cd finance-saas-platform
pnpm install
pnpm dev
```
